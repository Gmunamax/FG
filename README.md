# Project "FG"
_Inspired by Scott Cawton's Five Nights at Freddy's franchise_

FG is a game, inspired by Five Nights at Freddy's franchise. This game will be fast, aggressive and short.

FG uses [FGengine](https://github.com/Gmunamax/FGengine) - an engine, created specifically for this game, which, however, can also be used in your own project.

The game is not finished yet, for now, only key features are being implemented.
