# FGengine

<p>FGengine is a simple engine for my game "FG".</p>
<p>The name FGengine stands for "Fan Games engine". Although the engine currently isn't specifically geared toward fan games, I plan to use it to develop one, so in the future I’ll likely tailor it specifically for creating fan games.</p>


## Project status

FGengine currently is in early development state, it has almost nothing yet, but I do my bests to expand it's functionality with every release.


## Dependencies

FGengine uses these external dependencies:
* SDL2

FGengine can't work without them.

Also, these dependencies are required for building projects that use FGengine:
* GLM

Install them via your package manager on your system.
